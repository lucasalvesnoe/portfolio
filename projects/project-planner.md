## What it is

Professional project manager with real-time collaboration — the web alternative to MS Project, at version 2.4.0. It has a Gantt chart, baselines to compare planned against actual, multi-user support with cloud persistence, and an AI layer to assist planning. React + TypeScript on Supabase, with performance optimisation recorded in the history and deployment on Netlify. At 71 commits, it is the third-largest history in the archive.
