## O que é

Gerenciador de projeto profissional com colaboração em tempo real — a alternativa web ao MS Project, na versão 2.4.0. Tem gráfico de Gantt, baselines para comparar o planejado contra o executado, multiusuário com persistência em nuvem e uma camada de IA para apoio ao planejamento. React + TypeScript sobre Supabase, com otimização de performance registrada no histórico e deploy em Netlify. São 71 commits, o terceiro maior histórico do acervo.
