## What it is

A set of Claude Code skills, versioned and synced across machines — automation of the architecture and pre-sales work itself. It includes `discovery` (maps the information gaps in a project not yet understood and delivers a gap map ranked by criticality), `arquiteta` (generates the full architecture dossier — C4, flows, data model and MDM, security and LGPD (Brazil's GDPR), non-functional requirements, ADRs, risks and roadmap — as navigable HTML), `documenta` and `entrega` (which together compose a documentation and deployment release, with the dangerous layer deliberately kept apart from the harmless one), `sharepoint` (sanitised technical hand-over, with no `node_modules`, `.git`, `.env` or hardcoded secrets) and `atualiza` (syncs config between PCs and seeds a new project).
