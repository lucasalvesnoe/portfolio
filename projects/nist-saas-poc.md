## What it is

SaaS platform for managing NIST 800-53 compliance, with separate backend and frontend. It organises the framework's controls into modules by category, runs interactive diagnostic questionnaires, and consolidates the result into a compliance-status dashboard with risk analysis. It has a conversational assistant that answers questions about the controls — the point being that nobody needs to have the NIST catalogue memorised to operate the tool. The repository includes an installer, a quick-start guide and a client presentation script.
